OpsWarden `v1.0.16` makes operational state faster to scan and the War Room
feel genuinely shared without expanding the product beyond its existing data.

## Operational overview

- Overview gains a full-width calendar above its existing summaries, with
  Week and Month views for Incidents, Releases and automation Runs.
- Calendar events keep a stable visual vocabulary: Incidents are red, Releases
  blue and Runs neutral gray; every event links back to its operational object.
- Operational badges now share one opaque panel grammar, explicit icons and a
  reduced semantic palette across lifecycle, severity, automation and access
  states.

## War Room presence

- Incident activity keeps every system event as its own readable line and uses
  the shared badges for state and severity transitions.
- Authorized co-watchers see each other's ephemeral pointer in real time. The
  coordinates are normalized, rate-limited, scoped to one watched Incident,
  never persisted and never echoed to the sender.
- The pointer uses OpsWarden's existing gold identity and expires quickly when
  movement stops, preserving focus when nobody is actively collaborating.

## Quality and compatibility

- English and French copy, WebSocket documentation and deterministic demo data
  cover the new surfaces.
- The same web client powers browsers and the thin Tauri desktop shell; Linux,
  Windows and macOS packages therefore receive the new interface together.
- Unit, integration and two-browser E2E tests lock the calendar boundaries,
  badge grammar, event rendering and cursor authorization contract.
