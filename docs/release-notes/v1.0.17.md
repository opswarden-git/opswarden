OpsWarden `v1.0.17` completes the frontend refonte while preserving the
existing API, permissions and operational lifecycle contracts.

## Operational workspace

- The application shell, navigation and page geometry now follow one compact
  desktop grammar across Overview, Incidents, Releases, Runs and Settings.
- Incident and Release rooms use clearer context panels, unread state and
  activity timelines without removing system events or role boundaries.
- Team, Rules and Integrations expose denser resource-oriented controls with
  consistent tables, filters, actions, skeletons and responsive behavior.

## Collaboration and notifications

- Incident read state and release step events are persisted and delivered over
  the existing real-time channel.
- Desktop notifications are explicit opt-in, localized and suppressed while
  the application window is already active.
- Conversation attachments, reactions, presence and direct messages remain in
  the same chronological operational record.

## Quality and documentation

- English and French catalogues are kept in strict parity, including server
  errors, automation states, placeholders and accessible labels.
- Source coverage, migration policy, dependency audits, browser journeys and
  source hygiene are enforced by the release gate.
- The public documentation and generated product inventory now share one wiki
  shell, navigation model and search surface.
