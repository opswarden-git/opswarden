    Events and realtime

    Domain events, the scope each is delivered to, and the matching WebSocket frame. A Team scope reaches every member; a Users scope targets only the two named participants.

    Domain events

    DomainEvent

    server/src/domain/event.rs
    VariantScopeFrameIntent
    IncidentCreatedteamincident_createdA newly persisted incident. Clients use the severity to notify a direct critical creation without waiting for a later status transition.
    IncidentStateChangedteamincident_state_changed—
    IncidentEscalatedteamincident_escalated—
    IncidentAssignedteamincident_assigned—
    TimelineEntryAddedteamtimeline_entry_added—
    TimelineEntryEditedteamtimeline_entry_editedA timeline entry's content was edited. `edited_at` is the new stamp.
    ReactionAddedteamreaction_addedA user added an emoji reaction to a timeline entry.
    ReactionRemovedteamreaction_removedA user removed an emoji reaction from a timeline entry.
    RuleTriggeredteamrule_triggeredAn automation rule fired and its reaction succeeded (Phase 2). Carries the opened incident when the reaction created one (`CreateIncident`), `None` for side-effect reactions like `Notify`.
    RuleFailedteamrule_failedAn automation rule matched but its reaction failed (Phase 2).
    MemberKickedteammember_kickedA member was removed from a team without being banned.
    MemberBannedteammember_bannedA temporary or permanent ban was recorded. `until` is `None` for a permanent ban. The target may already be outside the team.
    PrivateMessageReceivedparticipantsprivate_message_receivedA private message was sent. Unlike every other event this is *not* team-scoped: it must reach exactly the two participants (sender + recipient), never a whole team. See `delivery`.
    PrivateMessageEditedparticipantsprivate_message_editedA private message body was edited by its original author.
    ReleaseStepValidatedteamrelease_step_validatedA release step was validated. Team-scoped.
    ReleaseStateChangedteamrelease_state_changedA release's *effective* state changed — including the derived `blocked`/auto-unblock transitions driven by linked incidents. Team-scoped.
